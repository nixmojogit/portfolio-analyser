Overview
Three Strategic Goals
Goal 1 — G1
Existing Portfolio Recommendations
Analyse current holdings and generate actionable Buy / Hold / Reduce / Exit recommendations backed by quantitative scoring and market sentiment.
Daily run All holdings
Goal 2 — G2
New Stock Discovery
Screen and recommend new stocks not currently in the portfolio across three complementary discovery modes — gap fill, peer comparison, and diversification.
Weekly run 3 modes
Goal 3 — G3
Portfolio Balancing & Optimisation
Ensure proportional distribution across sectors. Detect allocation drift, compute correlation, and generate specific rebalancing actions using G2 candidates.
Quarterly Event-driven

G2 — Three Discovery Modes

🎯 Mode A — Gap Fill

Identifies sectors where portfolio is underweight vs target allocation. Finds best-scoring stocks in those sectors from Nifty index constituents.

Initiate

🔄 Mode B — Peer Compare

For each sector you own, finds peers that score 15+ points higher than your existing holding. Recommends Switch or Distribute based on score gap.

SwitchDistribute

🌐 Mode C — Diversifier

Finds high-scoring stocks (65+) with low correlation (<0.7) to all existing holdings. Pure diversification opportunities regardless of sector allocation.

Initiate

Two-Stage Evaluation: Stage 1 scores all candidates on F, T, V, R (no Claude AI). Stage 2 enriches top 10 per mode with news sentiment via Claude AI. Final ranking re-orders by full F+T+V+R+S score. Top 5 per mode displayed.

Architecture Principles

SKILLS.md Design Contract

66 discrete skills defined before coding. Every capability tracked with ID, layer, inputs, outputs, dependencies and status.

Cache-First Pattern

Every external call checks SQLite cache first. TTLs per skill — from 1h (snapshots) to 168h (sector universe).

Configuration-Driven

Zero hardcoded thresholds. All weights, limits, sector targets in YAML. Behaviour changes via config — no code edits.

Recommendation Engine
Enriched Recommendation Reason

Every recommendation reason is built from three components combined — not just a score label.

Part 1 — Core Action

The net action from G1 stock score + G3 portfolio action combined. e.g. "Technology overweight — Hold rather than add despite strong score."

Part 2 — Fundamental Driver

Single most significant fundamental signal — surfaces worst red or strongest green. e.g. "Revenue growing strongly with expanding margins."

Part 3 — Market View

Sentiment + analyst signal. e.g. "Positive news sentiment. Analyst consensus is Buy. Analysts see 18% upside to target."

EXAMPLE OUTPUT
Strong stock score (72/100). No portfolio rebalancing conflict — proceed with confidence.
Fundamentals: Revenue growing strongly with expanding margins.
Market view: Positive news sentiment (Jio growth). Analyst consensus is Buy. Analysts see 18% upside to target.
